# Authenticator Driver for Nails MFA Module

![license](https://img.shields.io/badge/license-MIT-green.svg)
[![tests](https://github.com/nails/driver-multi-factor-auth-authenticator/actions/workflows/build_and_test.yml/badge.svg )](https://github.com/nails/driver-multi-factor-auth-authenticator/action)

This is the "Authenticator" driver for the Nails MFA module, it allows verification codes to be sent via authenticator on login.

Documentation: [https://docs.nailsapp.co.uk/modules/multi-factor-auth/drivers/authenticator](https://docs.nailsapp.co.uk/modules/multi-factor-auth/drivers/authenticator)
